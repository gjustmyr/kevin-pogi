```bash

npm start
```

### 2. Start Frontend
```bash
cd client
npm start
```

### 3. Test Login
- Go to: `http://localhost:4200/login`
- You'll see the reCAPTCHA widget
- Check "I'm not a robot"
- Login successfully! ✅
